# VideoMergingTool 6.0.1

本次为向后兼容的修复版本，目前提交至 dev，尚未发布正式 Release。

## 修复

- 修复音频转码出现时间戳倒退（AAC `Queue input is backward in time`、音频 `Non-monotonic DTS`）导致合并任务失败的问题。
- 对明确的音频时间戳异常，仅重试当前输入一次，通过重采样和连续采样时钟校正音频；不改变原视频编码方案，不修改源文件、不删除音轨，也不重跑其他已完成片段。
- 音频封装复制失败时允许定向转为音频重编码；正常素材保持原处理路径，Fast 模式仍只进行流复制。
- 音频错误及仅音频处理任务不再无意义地触发 GPU→CPU 回退；任务终止后不再启动回退重试。
- 保留严格错误检查、处理后校验以及停止／跳过策略，不掩盖真实损坏、磁盘、权限或未知错误。

## 验证

- 165 项 Python 测试、6 项前端测试通过。
- 使用真实 FFmpeg 合成音频时间戳倒退样本，验证定向恢复、音轨保留、起止时间、DTS 单调性及三片段完整合并。
- 原始问题素材和 Windows/NVENC 环境仍需实机验收；合成测试不等同于全部设备和素材均已验证。

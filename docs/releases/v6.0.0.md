# VideoMergingTool 6.0.0

本次为大版本更新：重构桌面工作区，增加视频完整性检查和损坏文件处理策略，并统一 macOS 安装包。

## 全新的桌面工作区

- 使用 Vue 3、Element Plus 和 AG Grid Community 重构界面；安装包内置前端资源，无需用户安装 Node.js，也不依赖 CDN。
- 支持选择整个文件夹，或直接选择一个、多个视频。
- 点击文件名可使用系统默认播放器预览；可标记顺时针旋转 90°、排除或恢复视频，不修改源文件。
- 保留横屏、竖屏等视觉分组；实际合并仍使用统一排序规则。旋转、排除不会让视频在表格中跳组移动。
- 文件名列使用剩余空间，其他列按内容自适应；支持拖动调整、保存和重置列宽。
- 日志采用虚拟列表，支持筛选警告、错误，以及导出完整处理日志。

## 视频检查与任务容错

- 新增基础检查、快速抽检、完整解码检查，默认采用快速抽检。
- 可选择遇错停止，或跳过已确认损坏的视频并继续；默认遇错停止。
- 转码失败时隔离单个输入，GPU 路径可回退 CPU 重试；剩余视频保持原有相对顺序。
- 任务结果区分全部完成、部分完成、失败、已取消，并提供输出文件、跳过清单和原因。
- 输出先写入临时文件，验证通过后再发布；处理失败不会用不完整文件覆盖已有成片。
- 改进取消任务与并发处理的清理逻辑，避免失败后继续启动多余处理任务。

## 格式兼容与交互修复

- 改进 WMV 等视频的音轨兼容处理：在 Optimal / Extreme 模式下，必要时将 MP4 不支持的音频编码转换为兼容编码；Fast 模式仍只进行流复制。
- 优化文件、文件夹选择窗口的中文标题和筛选器，中文系统优先使用中文文案；系统自带按钮语言仍由操作系统提供。
- 修复测试配置串扰和 Windows 路径断言，覆盖 Windows、Linux、Intel Mac、Apple Silicon Mac 四类测试环境。

## 安装包与发布验证

- Windows：下载 `VideoMergingTool-Setup.exe`。
- macOS：下载 `VideoMergingTool-macos-universal.dmg`，同一安装包支持 Intel 与 Apple Silicon，无需区分下载。
- Linux：下载 `VideoMergingTool`，赋予执行权限后运行。
- 安装包内置 FFmpeg / FFprobe；macOS 的应用运行时和媒体工具均检查双架构，下载依赖校验 SHA-256。
- 发布流程验证离线界面资源和真实合并；同一 macOS DMG 分别在 Intel、Apple Silicon 运行验证，通过后才发布附件。

## 升级与使用注意

- 快速抽检只覆盖视频的部分位置，通过抽检不代表整段视频完全无损坏；重要素材可选择完整检查。
- “跳过继续”仅跳过确认损坏的输入。磁盘、权限、编码器配置错误，以及不能可靠归因的故障仍会停止任务。
- 部分完成表示至少一个视频被跳过，请检查结果清单，不要将其当作全部素材均已合并。
- Universal 2 表示 CPU 架构兼容，不代表所有旧版本 macOS 都经过验证；本次 macOS 发布验证环境为 macOS 15。
- 未配置发行者签名或公证的构建，可能出现 Windows SmartScreen 或 macOS Gatekeeper 提示。
- 视频处理在本地完成，不上传视频到服务器。

详细架构、检查策略与开发说明见仓库中的 `docs/6.0.0.md`。
